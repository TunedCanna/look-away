# Look Away

A gentle 20-20-20 eye-break reminder that runs in the browser. Every 20 minutes it chimes, shows a pop-up, and puts up a 20-second "look into the distance" countdown.

- Single self-contained `index.html`: no install, no build step, no network requests.
- Settings are saved in the browser's local storage.
- Works best in Edge or Chrome opened from its web address (pop-ups, "install as app" and the optional screen-lock pause need it).
